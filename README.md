# Controle-de-Ponto
Sistema de Controle de Ponto desenvolvido com HTML, CSS e JavaScript. Permite registrar entrada e saída de funcionários, consultar data e horário, capturar fotografias pela câmera e armazenar os registros no LocalStorage. Projeto desenvolvido como atividade acadêmica do curso Técnico em Desenvolvimento de Sistemas do SESI/SENAI.

# ⏰ Controle de Ponto

Sistema web de controle de ponto desenvolvido com **HTML, CSS e JavaScript**. A aplicação permite registrar a entrada e saída de funcionários, capturar uma fotografia utilizando a câmera do dispositivo e armazenar as informações no LocalStorage.

## 🎓 Atividade acadêmica

Este projeto foi desenvolvido como uma atividade do curso **Técnico em Desenvolvimento de Sistemas do SESI/SENAI**, com o objetivo de praticar conceitos de desenvolvimento web, manipulação do DOM, JavaScript, acesso à câmera e armazenamento de dados no navegador.

## 🚀 Funcionalidades

- 📅 Exibição da data atual
- 📆 Exibição do dia
- 🕐 Exibição do horário
- 👋 Saudação ao usuário
- 📷 Abertura e fechamento da câmera
- 📸 Captura de fotografia
- 👤 Cadastro do nome do funcionário
- 📝 Registro de entrada ou saída
- 💾 Armazenamento dos dados utilizando LocalStorage
- 📋 Exibição do último registro realizado

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Canvas
