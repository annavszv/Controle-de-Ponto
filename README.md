# Controle-de-Ponto
Sistema de Controle de Ponto desenvolvido com HTML, CSS e JavaScript. Permite registrar entrada e saída de funcionários, consultar data e horário, capturar fotografias pela câmera e armazenar os registros no LocalStorage. Projeto desenvolvido como atividade acadêmica do curso Técnico em Desenvolvimento de Sistemas do SESI/SENAI.
